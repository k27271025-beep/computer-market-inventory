Приложение для магазина компьютерной техники: ведёт учёт демо-образцов на витрине, их износа, обслуживания и уценки при продаже.

## Возможности

- **Реестр оборудования**: серийный номер, название, категория, дата выставления на витрину, процент износа, цена, статус.
- **Автоматический пересчёт износа** в зависимости от того, сколько устройство простояло на витрине.
- **Журнал обслуживания**: тип работ, дата, исполнитель (сотрудник), стоимость, комментарий. Устройство на время ремонта получает статус «На обслуживании».
- **Уценка и продажа** демо-образца: цена с учётом износа, статус «Продано с уценкой».
- **Проверки ввода**: уникальность серийного номера, обязательные поля, дата не в будущем.
- Справочники: категории, статусы, сотрудники, виды работ.

## Технологии

- C#, .NET Framework 4.7.2, Windows Forms
- Microsoft SQL Server (LocalDB), параметризованные SQL-запросы через **Dapper**
- Слой доступа к данным `DbService`, модели в папке `Models/`
- Строка подключения в `App.config` (`DefaultConnection`)

## Структура

```
ComputerMarketInventory/
├── MainForm.cs              главное окно: список техники, фильтры, пересчёт износа, уценка
├── AddEditEquipmentForm.cs  добавление и редактирование устройства
├── MaintenanceForm.cs       оформление обслуживания
├── MaintenanceViewForm.cs   история обслуживания
├── DbService.cs             подключение к БД
└── Models/                  модели таблиц и справочников
```

## Как запустить

1. Откройте `.sln` в **Visual Studio 2022** (рабочая нагрузка «Разработка классических приложений .NET»).
2. Создайте базу данных в SQL Server (подойдёт бесплатный LocalDB, он ставится вместе с Visual Studio). Имя базы и структура таблиц видны в файле `ComputerMarketDBDataSet.xsd`.
3. Строка подключения лежит в `App.config` и по умолчанию указывает на `(LocalDb)\MSSQLLocalDB`. При необходимости поменяйте имя сервера.
4. Нажмите **F5**.

Пакеты NuGet (Dapper и др.) Visual Studio восстановит сама при первой сборке.
